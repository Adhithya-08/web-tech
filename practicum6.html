CSS Positioning Techniques

CSS positioning controls how HTML elements are placed on a webpage. This demonstration explains five important positioning properties.

1. Static Position

Static is the default position of an HTML element.

This box uses position: static.

2. Relative Position

Relative positioning moves an element from its original position.

This box uses position: relative.

3. Absolute Position

Absolute positioning places an element relative to its nearest positioned parent.
